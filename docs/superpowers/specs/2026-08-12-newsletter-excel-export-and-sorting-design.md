# تصدير النشرة كملف Excel + التحكم بترتيب المنتجات

**التاريخ:** 2026-08-12
**الحالة:** معتمد

## الهدف

إضافة ميزتين مترابطتين لصفحة نشرة الأسعار (`/newsletter`):

1. **تصدير Excel** — تنزيل النشرة كملف `.xlsx`، كل براند وتحته منتجاته.
2. **التحكم بترتيب المنتجات** — فرز منتجات كل براند حسب **السعر** أو **الاسم**، **تصاعدياً** أو **تنازلياً**.

الترتيب إعداد واحد يؤثر على المعاينة وعلى كل صيغ التصدير (PNG / PDF / Excel) — فتبقى متطابقة دائماً.

## القرارات المعتمدة

| القرار | الاختيار |
|---|---|
| شكل ملف الإكسل | ورقة واحدة، صف عنوان مدموج لكل براند ثم منتجاته تحته |
| نطاق الترتيب | النشرة والإكسل معاً |
| التجميع حسب الفئة | يبقى كما هو — الفرز يطبَّق **داخل** كل فئة |
| أعمدة الإكسل | المنتج، الذاكرة، السعر (مطابق لما يظهر في النشرة) |
| مكتبة التوليد | `exceljs@4.4.0` عبر `import()` ديناميكي |

**لماذا exceljs:** يدعم دمج الخلايا وتلوين الصفوف وتجميد الرأس و `rightToLeft` على مستوى الورقة — وكلها لازمة لشكل «صف براند ملوّن ثم منتجاته». حزمة `xlsx` على npm عالقة عند 0.18.5 بثغرات معروفة وبلا تنسيق، و CSV لا يدعم أياً من ذلك ويعاني من ترميز العربية في إكسل. الاستيراد الديناميكي يمنع دخول ~900KB إلى الحزمة الرئيسية.

## البنية

### 1. إعدادات الترتيب — `src/features/newsletter/lib/poster.ts`

```ts
export type SortField = 'price' | 'name';
export type SortDirection = 'asc' | 'desc';

export interface SortSettings {
  field: SortField;
  direction: SortDirection;
}

export const DEFAULT_SORT: SortSettings = { field: 'price', direction: 'asc' };
```

يُضاف الحقل `sort: SortSettings` إلى `PosterSettings` وإلى `DEFAULT_POSTER_SETTINGS`.

### 2. الحفظ — `hooks/usePersistentSettings.ts`

يُدمج `sort` مع الافتراضي داخل `loadSettings()` بنفس نمط `contact` و `theme`:

```ts
sort: { ...DEFAULT_SORT, ...(parsed.sort ?? {}) }
```

**مفتاح التخزين يبقى `bareq_poster_settings_v9`** — الدمج يضمن أن الإعدادات المحفوظة عند المستخدمين لا تنكسر ولا يفقدون تخصيصاتهم.

### 3. الفرز — `buildPoster()` في `poster.ts`

يُستبدل المقارن الثابت الحالي بدالة معزولة قابلة للاختبار:

```ts
export function compareLines(
  a: PosterLine,
  b: PosterLine,
  sort: SortSettings
): number
```

الترتيب:

1. **الفئة أولاً** — `categorySortKey()` كما هو (جوال ← تابلت ← ساعات ← اكسسوارات ← أخرى).
2. **ثم حقل الفرز:**
   - `name`: `a.name.localeCompare(b.name, 'ar', { numeric: true })` — `numeric` كي يأتي `iPhone 15` قبل `iPhone 100`.
   - `price`: فرق عددي.
3. **الاتجاه:** `desc` يعكس ناتج الخطوة 2 فقط، **لا يعكس ترتيب الفئات**.

**المنتجات بلا سعر** (`price === null`) تُدفع إلى آخر الفئة دائماً، في الاتجاهين — قبل تطبيق معامل الاتجاه، وليس عبر `Infinity` كما في الكود الحالي (الذي كان سيقفزها إلى الأعلى في التنازلي).

ترتيب مجموعات البراندات نفسها يبقى كما هو (`b.lines.length - a.lines.length`) لأنه يخدم موازنة الأعمدة في المعاينة.

### 4. مولّد الإكسل — `src/features/newsletter/lib/exportExcel.ts` (ملف جديد)

```ts
export async function exportPosterAsExcel(
  groups: PosterBrandGroup[],
  settings: PosterSettings,
  fileName: string
): Promise<void>
```

يستقبل **نفس** `groups` التي تُرسم منها المعاينة، فلا يوجد مصدر ثانٍ للحقيقة ولا احتمال اختلاف بين الملف والنشرة.

بنية الورقة (واحدة، اسمها `نشرة الأسعار`، `views: [{ rightToLeft: true }]`):

| الصف | المحتوى |
|---|---|
| 1 | عنوان مدموج `A1:C1` — `BAREQ Tel — نشرة أسعار المفرق/الجملة — <التاريخ>` |
| 2 | رؤوس الأعمدة: **المنتج \| الذاكرة \| السعر** — مجمّدة (`views.ySplit = 2`) |
| 3+ | لكل براند: صف عنوان مدموج `A:C` بخلفية ملوّنة ونص أبيض عريض، ثم صفوف منتجاته، ثم صف فارغ |

تفاصيل:

- **لون صف البراند** من `resolveGradients(settings.theme).brand.from` — نفس لون بلوك البراند في المعاينة. يُحوَّل من `#rrggbb` إلى `FFrrggbb` (تنسيق ARGB الذي يطلبه exceljs).
- **السعر** يُكتب كرقم `number` بتنسيق `'#,##0'`، لا كنص — ليبقى قابلاً للجمع داخل إكسل. القيمة `null` تُكتب `'—'`.
- **الذاكرة** تمر عبر `toEnglishDigits()` كما في المعاينة.
- **المنتجات المميّزة** (`settings.productColors[line.id]`) تأخذ خلفية بنفس اللون مخفّفة وحدّاً يمينياً بلونه الكامل — مطابقة لتمييزها في النشرة.
- عرض الأعمدة: 34 / 14 / 14.
- التنزيل: `workbook.xlsx.writeBuffer()` ← `Blob` ← رابط مؤقت ← `URL.revokeObjectURL` بعد النقر.

`buildFileName()` في `exportImage.ts` يُستخدم كما هو: `buildFileName('list', 'xlsx')`.

### 5. واجهة التحكم — `components/PosterToolbar.tsx`

- **الشريط العلوي:** قائمتا `Select` جديدتان بجانب «سعر» و«أعمدة»:
  - `ترتيب: السعر` / `ترتيب: الاسم`
  - `تصاعدي ↑` / `تنازلي ↓`
- **زر Excel** أخضر بأيقونة `FileSpreadsheet` بجانب زرّي PNG و PDF، معطّل أثناء التصدير.
- `PosterToolbarProps` يكتسب `onExportExcel: () => void`.

### 6. الصفحة — `pages/NewsletterPage.tsx`

`handleExportExcel` بنفس نمط `handleExportPng`/`handleExportPdf`: يضبط `exporting`، ينادي `exportPosterAsExcel(groups, settings, ...)`، ويعرض `toast` نجاح أو فشل.

## معالجة الأخطاء

- فشل تحميل المكتبة ديناميكياً أو فشل التوليد → `catch` يسجّل في الـ console ويعرض `toast.error('فشل تصدير Excel')`، ويعيد `exporting` إلى `false` في `finally` — نفس سلوك PNG و PDF الحالي.
- `groups` فارغة → الصفحة تعرض `EmptyState` ولا تُظهر شريط الأدوات أصلاً في تلك الحالة؛ ومع ذلك يخرج المولّد بورقة تحوي العنوان والرؤوس فقط بدلاً من الانهيار.

## التحقق

المشروع لا يحتوي إطار اختبارات (لا vitest ولا jest في `package.json`)، لذا التحقق:

1. `npm run build` — يمر بلا أخطاء TypeScript.
2. `npm run lint` — بلا أخطاء جديدة.
3. تشغيل يدوي على `/newsletter`:
   - تبديل الترتيب بين السعر/الاسم وتصاعدي/تنازلي، والتأكد من تغيّر المعاينة داخل كل فئة مع بقاء ترتيب الفئات ثابتاً.
   - تصدير Excel وفتحه: التحقق من اتجاه الورقة RTL، صفوف البراندات الملوّنة، الأسعار كأرقام، وتطابق الترتيب مع المعاينة.
   - إعادة تحميل الصفحة والتأكد من حفظ إعداد الترتيب.

## خارج النطاق

- تصدير الكفالات أو بيانات التواصل أو الوكلاء إلى الإكسل — الملف قائمة أسعار، لا نسخة من البوستر.
- ورقة منفصلة لكل براند، أو عمود براند مسطّح للفلترة.
- التحكم بترتيب البراندات نفسها.
- تصدير سعري المفرق والجملة معاً في ملف واحد.
